# Spanish Coach 🇪🇸

Персональный чат-агент для изучения испанского языка. Ведёт ежедневные тренировки
в чате Коворкера: даёт задания по глаголам и лексике, проверяет ответы, объясняет
ошибки и следит за прогрессом.

## Как это работает

- **Каждый день в 12:00** (локальное время) запускается автоматизация «Испанский:
  ежедневная тренировка». Агент читает файлы проекта и начинает сессию в чате.
- Задания выдаются **по одному**. Вы вводите ответ текстом (или букву варианта),
  агент проверяет, объясняет ошибку по-русски и даёт следующий вопрос.
- Проверка снисходительная: опечатки и пропущенные ударения (hablas ≈ hablás)
  не считаются ошибкой, но агент вежливо отмечает верное написание.

## Структура

| Файл | Что хранится |
|---|---|
| `settings.yml` | Уровень, длительность сессии, включённые типы заданий |
| `curriculum/verbs.yml` | Глаголы для тренировки спряжений (3 спряжения + неправильные + возвратные) |
| `curriculum/vocabulary.yml` | Существительные и прилагательные |
| `exercises.md` | Каталог типов заданий и правила их генерации |
| `progress.md` | Журнал сессий: ошибки и «слабые» слова |

## Как менять правила

Просто напишите агенту в чат, например:

- «добавь тип задания: составь предложение из слов в правильном порядке»
- «убери найди ошибку на этой неделе»
- «добавь глагол dormir в список» / «убери palabra из словаря»
- «давай сегодня только спряжения, без лексики»
- «переключись на pretérito» (когда придёт время)

Агент обновит `settings.yml` / `curriculum/*.yml` / `exercises.md` и покажет, что изменилось.
Можно и руками править YAML-файлы — агент подхватит изменения на следующей сессии.

## Как вести прогресс

После каждой сессии агент дописывает в `progress.md`: дату, что отрабатывали,
ошибки. Слова, в которых вы ошибаетесь, попадают в «зону внимания» и выпадают чаще.
