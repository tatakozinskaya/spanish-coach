# Каталог типов заданий

Агент генерирует задания по этим правилам. Типы можно включать/выключать в
`settings.yml` (ключ `exercise_types`) или попросить агента в чате.
Можно добавлять новые типы — просто допишите раздел по образцу.

Общие правила для всех типов:
- Задания выдаются по одному, с эмодзи-номером типа и короткой инструкцией по-русски.
- Ответ проверяется сразу; ошибка → объяснение по-русски + правильный ответ + через
  2-3 задания повтор того же глагола/слова.
- Проверка строгая (strict): ударения (tú, él, más…), ñ, ü, ¡/¿ обязательны.
  Опечатка или пропущенное ударение = ошибка: показать верное написание, объяснить
  смысл (sí/si, él/el), попросить переписать.

## translate_to_es — Переведи на испанский
**Формат:** «Переведи на испанский: „Он говорит“» → пользователь вводит предложение.
**Правила генерации:**
- Берём глагол из verbs.yml + местоимение/подлежащее + иногда слово из vocabulary.yml.
- Уровень A0: короткие предложения (3–5 слов), только presente.
- Принимается любой корректный вариант перевода, не только «эталонный»;
  допускаются варианты с опущенным местоимением (habla = él habla).
- Пример: «Ты помогаешь мне» → «Tú me ayudas» / «Me ayudas».

## conjugation_fill — Раскрой скобки
**Формат:** «Раскрой скобки: Nosotros ____ (hablar) español.» → пользователь вводит форму.
**Правила генерации:**
- Случайное лицо, глагол из списка; для неправильных — приоритет формы yo
  (hago, tengo, voy, soy, sé...), т.к. это самые частые ловушки A0.
- Для возвратных — вместе с местоимением: «Me ____ (llamo/llamarse)» → «Me llamo».
- Оценивается только форма глагола (+местоимение, если возвратный).

## multiple_choice — Выбери правильный вариант
**Формат:** «Выбери правильный вариант: Ella ___ al trabajo. a) voy b) va c) vas d) vamos»
→ пользователь отвечает буквой или словом.
**Правила генерации:**
- 3–4 варианта; дистракторы — реальные ошибки A0 (другое лицо, *haco, *tengo→teno и т.п.).
  Формы других времён не используем.
- По лексике: выбор артикля по роду (el agua / *la agua), согласование
  (casa grande / *casa granda), ser/estar.
- Эталон — буква варианта.

## find_the_error — Найди ошибку
**Формат:** «Найди ошибку в предложении: „Yo haco los deberes.“» → пользователь пишет,
что не так (можно своими словами по-русски или исправить по-испански).
**Правила генерации:**
- Ровно одна ошибка: форма глагола, род/артикль, согласование прилагательного,
  ser/estar, пропущенное местоимение у возвратного.
- После ответа показываем исправленное предложение и правило одной фразой.
- Если пользователь не может — подсказка по частям (указать слово, где ошибка).
