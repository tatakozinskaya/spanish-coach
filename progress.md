# Журнал тренировок

Формат записи (агент дописывает после каждой сессии):

```
## 2026-10-15 — 8/10
- Errors: hacer (yo→*haco), el agua (*la agua)
- Weak: hacer, agua, tercer persona de querer
- Notes: хорошо идут правильные -AR
```

«Weak»-слова агент подсовывает чаще (каждая 3-я генерация — из зоны внимания),
пока слово не пройдёт 3 раза подряд без ошибки.
